# Calibrate

1. Read `private/calibration/questions.md`, `private/goals.md` and the board. Add any new open points you notice (items marked [Unklar], "not yet answered", conflicts in the import log).
2. Ask Allan **one question at a time**, most useful first. Short, concrete, easy to answer by voice. Offer choices when that helps.
3. After each answer: write it into the right file (profile, application file, goals, health, wellbeing, CLAUDE.md for working-style rules), mark the question answered with the date, and say in one line where it went.
4. Stop when Allan says stop, or after about 10 questions, and list what changed.
5. Never ask what is already answered in the files. "Skip" moves a question to the end.
